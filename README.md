## Run the app

1. Install PostgreSQL and create a database named `myapp` with `createdb myapp`.
2. In `backend`, run `npm install`.
3. Start the backend by running `npm start` in `backend`.
4. Open `frontent/index.html` with VS Code Live Preview or another static server.

The backend runs on `http://localhost:3002` and creates the `tasks` table automatically. PostgreSQL connection settings are in `backend/server.js`.
